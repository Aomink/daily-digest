1. Claude Code 2.1.318(11/4)

何が起きたか

Claude Code 2.1.318 が出た(同梱された Agent SDK for Python 0.2.178 が11/4付)。主な変更は、claude apps gateway の mantle upstream で assume_role を使い他のAWSアカウントのロールを指定できること、modの $.model.fork に effort を指定して副次ジョブを低い effort で動かせること、claude auth status で claude.ai ログインの有効期限が見えること。--continue で会話が欠ける不具合も修正された。

なぜ役立つか

AWS複数アカウント構成でのコスト按分や、ログイン期限切れによる定期実行(claude -p)の突然の停止を事前に把握しやすくなる。リリース日はSDK側のリリースページで確認した。

2. Agent SDK / Claude Code 2.1.317 のフック失敗時ブロック(11/3)

何が起きたか

Agent SDK for Python 0.2.177(11/3)で、フックコールバックが失敗したときの挙動を指定する on_failure が追加された。"block" にすると、コールバックが例外を出した場合などに該当の操作を止める。既定は従来通り続行。Claude Code 2.1.317 には、クラウドの定期タスクに意図しないコネクタが付くと /schedule で警告する変更や、アカウントのメールアドレスをネットワークに送る前に確認する変更も入った。

なぜ役立つか

安全チェック用のフックが落ちたときに、素通りさせず止める「フェイルクローズ」にできる。無人実行のエージェントの権限管理に有用。古いCLIと組み合わせるとエラーになる点に注意。

claude-agent-sdk-python リリース / Claude Code CHANGELOG

3. Claude API: Messages の「スレッド」ベータ(11/2)

何が起きたか

Messages API にスレッド機能(ベータ)が追加された。ヘッダー message-threads-2026-08-12 で有効化し、会話をサーバー側に保持するため、以降のリクエストは新しいメッセージだけを送ればよい。最終リクエストから5分で期限切れ、最終利用から最大1時間以内に削除される。

なぜ役立つか

長い対話のたびに履歴全体を送り直す必要が減り、実装の簡素化と通信量の削減が見込める。ただし保持期間が短いため、長期の状態管理には別途保存が必要。

4. OpenAI Agents SDK (Python) v0.24.0-alpha.6(11/3、プレリリース)

何が起きたか

ターン単位でのセッション制御(ターンの取得、プロンプトの待機・誘導、キャンセル)、セッション状態の可搬な保存と復元、構造化出力オプション、ネイティブコマンド向けの NetworkPolicy、モデル不要でテストできる ScriptedResponses などが追加された。Runner の別名廃止や Turn.wait() の置換など、破壊的変更を含む。

なぜ役立つか

長時間動くエージェントの中断・再開や、CIでのモデルなしテストに使える。正式版ではなくアルファなので、本番投入は慎重に。最新の安定版は10/15の v0.24.0。
