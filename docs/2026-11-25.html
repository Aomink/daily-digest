2. Claude Code 2.1.331(11/23付)

何が起きたか

Code ModeがBedrock、Google Cloud、Microsoft Foundry、Claude Platform on AWSのターミナルセッションで使えるようになった。プラグインのマニフェストに optionalDependencies が追加され、claude doctor にAPI接続確認が加わった。不正な応答でMCPツール呼び出しが最大30分ハングし得る不具合も修正。

なぜ役立つか

MCPサーバー利用時の「固まって進まない」問題が減る。また管理対象の extraKnownMarketplaces は11/30以降デフォルトで自動更新になるため、固定したい組織は "autoUpdate": false を設定する必要がある。

3. Claude Opus 4.5 のAPI提供終了が予告(11/23付)

何が起きたか

Claude Opus 4.5(claude-opus-4-5-20251101 と claude-opus-4-5)は2027年1月22日にClaude APIから廃止予定。移行先としてClaude Opus 5.5が案内されている。

なぜ役立つか

エージェントや自動処理でモデルIDを固定している場合、期限までの見直しが必要。2か月ほど猶予があるので、設定の洗い出しと検証を計画できる。

4. Enterprise Frontier Safeguards(ベータ)と新しいwebhook(11/23付)

何が起きたか

Claude Platform等でベータ提供開始。対象組織向けにZero Data Retentionを提供し、プロンプトと応答の暗号化コピー(Sealed Safety Data)を自社クラウドのバケットへ送る仕組み。Anthropic管理のストレージを使うワークスペースは対象外。あわせて、バケットの日次チェック失敗・回復を通知する external_storage.failed / external_storage.recovered のwebhookも追加された。

なぜ役立つか

データ保持要件が厳しい組織が、高性能モデルでエージェントを運用する際の選択肢になる。対象条件の詳細は未確認なので、公式ページで確認を。
