以下は24時間より前の更新です。前回ダイジェスト(10/31)以降の見落とし防止のための参考掲載です。

何が起きたか

Claude Code 2.1.319(11/6)で、MCPサーバーがタスクとして実行したツール呼び出しをバックグラウンドに回し、完了後にClaudeへ結果を返す動作が入った。ほかに、許可確認待ちになる呼び出しを拒否して処理を続ける設定 permissions.denyInsteadOfPrompting も追加された。

Claude Platform では11/2に、会話をサーバー側で保持して以降は新しいメッセージだけ送れる「message threads」がベータで公開された(要ヘッダ)。11/5にはConsole組織向けのIP許可リスト(ベータ)も出ている。

なぜ役立つか

長時間のMCPツールを使うエージェントが待たされにくくなり、無人実行では確認待ちで止まる問題を避けやすい。message threads は長い会話のリクエスト量削減に使える可能性がある(詳細は公式を要確認)。
