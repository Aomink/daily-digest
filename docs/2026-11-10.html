1. Claude Fable 5.2 / Mythos 5.2 が登場

何が起きたか

11/9、claude-fable-5-2 と claude-mythos-5-2 が公開された。どちらも1Mトークンのコンテキストと最大128k出力、常時オンのadaptive thinkingを持つ。料金は入力$8・出力$40(/MTok)で、Fable 5.1より下がった。Mythos 5.2は、サイバー検証プログラムなどで確認済みの組織に限定される。30日保持が必須で、ZDR環境では原則使えない。

なぜ役立つか

エージェント用のモデルを選び直す材料になる。単価が下がったので、長時間タスクのコスト見積もりを更新できる。ZDR前提の環境では使えないため、導入前に要件の確認が必要。

2. API側の破壊的変更: computer use のツールセットと thinking の検証

何が起きたか

Fable 5.2 / Mythos 5.2 のcomputer useは新ツールセット computer_toolset_20260801 が必須で、computer_20251124 を宣言すると(Amazon Bedrock以外では)400エラーになる。また、system・tools・過去メッセージを書き換えたうえで後のターンのthinkingブロックを送り返すと、全アカウントで400になる(prefix check)。thinkingブロックは発行したアカウント(または連携アカウント)でしか使えない。

なぜ役立つか

ブラウザ操作系のエージェントや、履歴を加工して再送する自作ループは、移行時に落ちる可能性がある。事前にツール定義とコンテキスト編集の処理を確認しておくとよい。

3. Fable 5.2 の fast mode とモデル切替・advisorの制約

何が起きたか

Fable 5.2はClaude APIで speed: "fast" が使え、出力速度は最大2.5倍。料金は入力$16・出力$80(/MTok)。会話の途中でFable/Mythos 5.2に切り替えても他モデルの推論は引き継がれるが、戻すと5.2のthinkingは破棄される(リクエスト自体は成功)。advisorツール(ベータ)では、5.2系のexecutorのadvisorは5.2系のみ。

なぜ役立つか

待ち時間が問題になる対話型エージェントでは、コストと速度のトレードオフを選べる。マルチモデル構成やadvisor利用時の組み合わせ制約も把握できる。

4. Claude Code 2.1.321: Fable 5.2 が既定に、mods まわりの権限変更

何が起きたか

11/9リリース。Fable 5.2が既定のFableモデルになった(1M、$8/$40)。保存済みのFable 5.1選択は fable に移る(戻すには /model claude-fable-5-1)。claude remote-control --settings <file> で、起動する全セッションに設定ファイルを適用できる。Claudeが書いたmodsは、autoやbypassモードでは確認なしに有効化されなくなり、dontAskモードでは読み込まれない。fast modeは、モデルを切り替える前に同じモデルの標準速度へ戻る。

なぜ役立つか

モデルの既定値が変わるため、再現性が必要なCIでは明示的にモデルを固定したい。リモート運用では設定ファイルを一括適用でき、管理が楽になる。
