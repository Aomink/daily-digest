1. Claude Code 2.1.331 リリース

何が起きたか

11/23リリース。Amazon Bedrock、Google CloudのAgent Platform、Microsoft Foundry、Claude Platform on AWS のターミナル利用で Code Mode が使えるようになった。プラグインマニフェストの optionalDependencies にも対応。MCPツール呼び出しが不正な応答で最大30分止まる不具合や、managed settings の承認待ちで claude plugin install が止まる不具合も修正された。

なぜ役立つか

third-party基盤でClaude Codeを使う組織で機能差が縮まる。MCPの長時間ハングが直るため、自動実行の安定性向上が期待できる。

2. Claude Code: 管理プラグインの自動更新が11/30から既定に

何が起きたか

同じ2.1.331の変更点として、managed の extraKnownMarketplaces にあるプラグインマーケットプレイスが2026年11月30日から既定で自動更新される。無効にするには "autoUpdate": false を設定する。

なぜ役立つか

組織でプラグインを配布している管理者は、更新を自動で受けるか固定するかを期限前に決めておける。

4. Enterprise Frontier Safeguards(ベータ)と組織Webhook

何が起きたか

11/23付。Claude Platformなどで、対象組織向けにゼロデータ保持を提供するベータ機能が始まった。プロンプトと応答の暗号化コピーは顧客自身のクラウドのバケットに送られる。あわせて、そのバケットの日次チェックが失敗/復旧したときの Webhook イベント external_storage.failed / external_storage.recovered(ベータ)が追加された。

なぜ役立つか

データ保持要件の厳しい企業が、エージェント運用で監査用データを自社管理下に置きやすくなる。保管先の障害にも通知で気づける。ただし対象は対象組織のみで、Anthropic管理ストレージのワークスペースは対象外。
