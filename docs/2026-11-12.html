2. 【期間外・11/10付】MCPにファイル受け渡し拡張の草案

何が起きたか

MCPのワーキンググループが、クライアントとツール間でファイルを直接やり取りする任意拡張 io.modelcontextprotocol/files を提案。モデルがファイル内容を扱わずに済む設計で、アップロードは upload_required 結果で起動する。実験段階で参照実装はまだなく、年内の安定化を目指すとのこと。

なぜ役立つか

大きなファイルをトークンに載せずにエージェントへ渡せる可能性がある。仕様はまだ流動的なので、試す場合はドラフトとして扱う。

3. 【期間外・11/9〜10付】Claude Code 2.1.321 / 2.1.322

何が起きたか

2.1.321(11/9)で Claude Fable 5.2 が既定のFableモデルになり、claude remote-control に --settings が追加、MCP OAuthでリダイレクト後に別ホストへ秘密情報が送られる不具合を含む74件を修正。2.1.322(11/10)ではVertexでのfast modeが追加された。

なぜ役立つか

MCPのOAuth接続を使っている場合は更新の優先度が高い。Remote Controlで複数セッションに同じ設定を配れる点も運用向き。

4. 【期間外・11/9付】Claude Fable 5.2 / Mythos 5.2 とAPI側の変更点

何が起きたか

Claude Platformのリリースノートによると、11/9に claude-fable-5-2 と、認証済み組織限定の claude-mythos-5-2 が公開。1Mトークン文脈、価格は入力$8/出力$40(MTokあたり)。同時にcomputer useには新しい computer_toolset_20260801 が必要になり、preserved thinkingのルールも厳格化された。
