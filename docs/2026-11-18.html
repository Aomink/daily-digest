1. Claude Code 2.1.327(11/17)

何が起きたか

11/17付のリリース。claude mcp add-json <name> - で標準入力からMCPサーバー設定のJSONを読めるようになり、トークンをコマンドラインに残さずに済む。claude mcp add が .mcp.json の他のトップレベルキーを消す不具合も修正された。ほかに、セッションの課金グループを示す attributionProject 設定の追加、ExitWorktree が未保存の作業がありそうなworktree削除前に確認する変更、Auto modeが Bash(pnpm dlx *) のような任意パッケージ実行を許可するルールを、より多く無視する変更などが入った。

なぜ役立つか

MCPサーバーを認証トークン付きで登録する運用が安全になり、既存の .mcp.json を壊す事故も避けやすい。Auto modeを使う場合は、許可ルールの効き方が変わる点を確認しておくとよい。

2. Claude API: 連携課金(Linked billing、ベータ)(11/17)

何が起きたか

11/17付で、自作アプリ上でのClaude利用料を、利用者自身のClaude組織に支払ってもらえるベータ機能が公開された。ベータヘッダー user-profiles-billing-2026-10-01 を使い、利用者が組織を連携した後、/v1/messages などのリクエストで billing_policy を指定して負担者を選ぶ。利用者はConsoleで上限設定や連携解除ができる。API利用料をAnthropicに直接払っている組織のみ対象。

なぜ役立つか

Claudeを組み込んだエージェントやツールを他者に配布する際、利用料を開発者が全額負担しなくてよい設計の選択肢になる。詳細な仕様や制限は公式ドキュメントで確認が必要。
