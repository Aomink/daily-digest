1. Claude Fable 5.2 / Mythos 5.2 が公開(API・Claude Code対応)

何が起きたか

11/9付で claude-fable-5-2 と claude-mythos-5-2 が登場。いずれも100万トークン文脈、最大出力128k、常時有効の適応型思考。Fable 5.2 は fast mode(speed: "fast")も使える。Mythos 5.2 は Anthropic の審査を通った組織向けに限定。両モデルは30日のデータ保持が前提で、ZDRでは原則使えない。

なぜ役立つか

エージェント用途で長い文脈を扱う場合のモデル選択肢が増える。データ保持の条件があるため、ZDR運用の環境では導入前に確認が必要。

2. Claude API の破壊的変更:thinking の再送チェックとcomputer useツール

何が起きたか

同じく11/9付のリリースノートに2点。(a) 「prefix check」が全アカウントで強制され、system・tools・過去メッセージを編集したうえでthinkingブロックを再送すると400エラーになる。(b) computer use は computer_toolset_20260801 が必須になり、旧 computer_20251124 は(Amazon Bedrock以外で)400エラーになる。

なぜ役立つか

履歴を加工して再送するエージェントや、computer useを使う自動化は突然失敗する可能性がある。コードの該当箇所を早めに確認したい。

3. Claude Code 2.1.321 / 2.1.322

何が起きたか

2.1.322(11/10): Vertex 上で fast mode がglobal・US・EUリージョンで使えるようになり、拒否された場合は通常速度にフォールバックする。2.1.321(11/9): Fable 5.2 が既定のFableモデルになり(1M文脈)、claude remote-control に --settings <file> を追加。自動・bypassモードでは、Claudeが書いたmodが確認なしで有効化されなくなった。

なぜ役立つか

Vertex経由で使っている場合は速度面の選択肢が増える。自動実行の運用では、mod有効化に確認が入る点が安全面で効く。
