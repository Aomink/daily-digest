1. Claude Code 2.1.316(10/31付)

何が起きたか

環境変数 CLAUDE_CODE_SUBAGENT_EFFORT でサブエージェントのeffortを指定でき、CLAUDE_CODE_DISABLE_ULTRATHINK で ultrathink キーワードを無効化できるようになった。Claude apps gateway には共有の予算枠(pooled group budgets)と managed.policy_mode: layered が追加された。Team/Enterprise の server-managed settings は承認プロンプトなしで適用される。

なぜ役立つか

サブエージェントを多用する運用で、コストと思考量を設定で調整しやすくなる。組織配布では、予算のグループ管理や設定の自動適用で運用の手間が減る。
