2. Claude Code 2.1.314 の補足(管理者向け項目)

何が起きたか

10/30リリース。昨日のダイジェストで触れた項目以外に、Claude apps gateway の upstream に groups を指定でき、IdPの特定グループの開発者だけを振り分けられるようになった。管理者がモデルの effort に上限を設けている場合に「Invalid effort level」で失敗する不具合も修正され、effort を下げて再試行し、実際の値を表示する動作になった。

なぜ役立つか
