1. Claude Code 2.1.332 リリース

何が起きたか

11/25付。MCPサーバー由来のスキルが server:skill として / メニューに出る(ベータ)。スキルやコマンドが読み込むインラインのシェルコマンドを拒否できる PreSkillShellCommand フックが追加された。Bedrock Mantle・Agent Platform・Foundry では、モード未指定ならauto modeで起動する(disableAutoMode を "disable" にすると無効化)。Foundry の既定モデルとAgent Platform/Foundryの sonnet エイリアスは Sonnet 5.5 になった。ほかにMCP SSEサーバーが止まる不具合の修正など、多数の修正がある。

なぜ役立つか

スキルのシェル実行をフックで統制でき、組織配布時の安全策になる。クラウド経由で使う環境ではauto modeが既定になるため、挙動が変わる点を事前に把握できる。
