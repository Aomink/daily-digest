1. Claude Code 2.1.314 がリリース

何が起きたか

権限設定 permissions.blockWritesOutsideWorkingDirectories が追加され、Write/Edit/NotebookEdit が作業ディレクトリ外のパスを全モードで拒否できるようになった。VS Code と Claude Desktop の Code タブには、200K トークン超の会話を放置した際に要約する「アイドル圧縮」も追加。claude -p は起動失敗時に無言で終了コード0を返す不具合が直り、エラー表示と終了コード1になった。

なぜ役立つか

自動実行(bypass系モード等)でも書き込み範囲を作業ディレクトリに限定できるため安全性が上がる。CIやスクリプトで claude -p を使う場合、失敗を終了コードで検知できるようになる。

2. Claude API に Usage and Cost Analytics API(ベータ)

何が起きたか

10/29付で、トークン使用量とコストを取得する /v1/organizations/analytics/usage と /cost がベータ公開された。モデル、ワークスペース、APIキー、ユーザー/サービスアカウントで絞り込める。従来のUsage and Cost APIとClaude Enterpriseの使用量レポートAPIは「legacy」扱い(引き続きサポート)。

なぜ役立つか

エージェントはトークン消費が読みにくいが、APIキーやワークスペース単位でコストを集計・監視する仕組みを自前で作りやすくなる。既存APIを使っている場合は移行ガイドの確認が必要。
