1. Claude Code 2.1.325: サンドボックス内Bashの権限と、gitの扱いが変更

何が起きたか

11/13リリース(公式changelog記載)。サンドボックス内で実行するBashコマンドも通常の権限確認フローに従うのが既定になった。従来どおり確認なしで動かすには sandbox.autoAllowBashIfSandboxed: true を設定する。また、信頼していないリポジトリでは読み取り専用のgitコマンドでも事前確認が入り、worktreeのセッションでは git bisect run などが拒否される。VS Code拡張にはプロンプト候補(Tabで採用)なども加わった。

なぜ役立つか

無人実行やCIでClaude Codeを使っている場合、更新後に確認待ちで止まる可能性がある。上記設定の有無を事前に見直しておくと安全に移行できる。
