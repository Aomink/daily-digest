1. Messages API に「Message threads」(ベータ)

何が起きたか

11/2付で、Messages API に message threads が追加された。会話をサーバー側で保持するため、2回目以降はリクエストに新しいメッセージだけを送ればよい。ベータヘッダ message-threads-2026-08-12 で有効化する。スレッドは最後のリクエストから5分で失効し、最終利用から最長1時間以内に削除される。Claude API、AWS上のClaude Platform、Google Cloud、Microsoft Foundryで利用可能とされている。

なぜ役立つか

長い会話やエージェントのループでは毎回履歴全体を送る必要がなくなり、リクエストが小さくなって初回トークンまでの時間も短くなる。5分で失効する点は、間隔が空く処理では設計に注意が必要。
