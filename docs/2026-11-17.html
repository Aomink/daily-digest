1. Claude Code 2.1.326 リリース

何が起きたか

11/16付。実験的機能の Code Mode(Claudeが JavaScript を書いてツールを呼ぶ方式)が agent teams 有効時にも使えるようになった。OpenTelemetry にホスト属性を付ける OTEL_RESOURCE_INCLUDE_HOST(既定はオフ)が追加され、--allowedTools 等の書式不正を起動時に警告する。また、サンドボックスや権限チェックが、PowerShell や一部のBashコマンド、ホーム配下の機密フォルダへの書き込みなどで、確認や拒否をより多く行うようになった。hook の "decision": "block" が効くケースも増えた。

なぜ役立つか

権限まわりが厳しくなったため、無人実行・定期実行の自動化では、今まで通っていた処理が止まる可能性がある。更新前に確認しておくと安全。計測を使っている場合はホスト属性も取れる。

2. Claude API: 旧モデルのテキスト透かしに関する記載

何が起きたか

11/16付のリリースノート。Claude Opus 4.6 / Opus 4.5 / Sonnet 4.5 / Haiku 4.5 の生成テキストには、対応プラットフォーム上でAnthropicのテキスト透かしが付く。リクエストで temperature・top_p・top_k を既定以外にすると、透かしが付かないことがある。

なぜ役立つか

生成物の扱い(出所表示など)を運用ルールにしている場合、サンプリング設定によって挙動が変わる点を把握しておける。
